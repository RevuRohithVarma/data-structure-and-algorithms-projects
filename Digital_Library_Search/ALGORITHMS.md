# Algorithm Notes

KMP: O(n+m) worst-case pattern matching.
Z: O(n+m) pattern matching through Z-values.
Rabin-Karp: expected/average linear behavior with polynomial rolling hash.
Aho-Corasick: multi-pattern trie/failure-link family; the dashboard provides a multi-pattern search mode.
Suffix Array + LCP/Kasai: suffix ordering and adjacent common-prefix computation for substring/similarity analysis.
Levenshtein: O(nm) edit distance for fuzzy search. Damerau extension handles transpositions.
Smith-Waterman: local sequence alignment. Needleman-Wunsch: global sequence alignment.
Ford-Fulkerson / Edmonds-Karp / Dinic: maximum-flow family for constrained allocation.
Bipartite matching: assignment demonstration.
Vertex Cover 2-approximation: maximal matching gives a factor-2 solution.
Knapsack/Subsetsum: optimization demonstrations.
Miller-Rabin: randomized primality test with deterministic bases for 64-bit integer range in this implementation.
Reservoir Sampling: uniform sample from a stream using O(k) storage.
