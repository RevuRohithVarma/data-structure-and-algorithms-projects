# DSA-3 CO / Module Mapping

| Module | Algorithms | Library purpose |
|---|---|---|
| M2 String | KMP, Z, Rabin-Karp, Aho-Corasick, Suffix Array, LCP/Kasai | Exact, multi-pattern, substring and similarity search |
| M3 DP | Levenshtein, Damerau, Needleman-Wunsch, Smith-Waterman, Interval/Bitmask/Tree/SOS concepts | Fuzzy search, alignment and algorithm lab |
| M4 Flow | Ford-Fulkerson, Edmonds-Karp, Dinic, Min-Cut, matching | Resource allocation and assignment demonstrations |
| M5 NP | reductions/SAT concepts, Vertex Cover 2-approx, Knapsack, Subset Sum, TSP/Hamiltonian concepts | Collection selection and optimization lab |
| M6 Randomized/Parallel | Miller-Rabin, randomized QuickSort, universal hashing, reservoir sampling, reduce, scan, parallel sort | Prime testing, robust sorting, random sampling and performance lab |

Module 1 is represented by the end-to-end TextHack-style API concept: every query is mapped to an algorithm family and exposed through the dashboard.
